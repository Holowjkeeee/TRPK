# Итерация 4.2 - навигация по категориям, карточки поединков и темы

## Выбор весовой категории
- Горизонтальная прокручиваемая лента категорий на странице сеток заменена на выпадающий список.
- Категории сгруппированы по возрастной группе через `optgroup`.
- Внутри возрастной группы варианты сортируются по лимиту веса.
- Для каждого варианта показываются вес, число допущенных спортсменов и назначенный ковёр.

## Карточка поединка
- Кнопка `Результат` переименована в `Внести результат`.
- Статус/способ победы и действие разнесены по двум областям footer карточки.
- Кнопка имеет `white-space: nowrap` и больше не должна выходить за границы карточки.
- Для древовидной сетки увеличены вертикальный шаг и расчётная высота карточки, чтобы соседние матчи не перекрывались.

## Светлая и тёмная темы
- В верхнюю панель добавлен переключатель `Тёмная` / `Светлая`.
- Выбор сохраняется в `localStorage` под ключом `matflow-theme`.
- Тёмная тема распространяется на панели, таблицы, формы, сетки, карточки матчей, протокол и основные служебные элементы.

## Проверка
- Python backend: `python -m compileall` - без синтаксических ошибок.
- JS из `.js` и `<script setup>` блоков `.vue`: `node --check` - без синтаксических ошибок.
- Полный `vite build` в рабочей среде сборки не запускался, так как зависимости npm отсутствуют локально, а доступ к npm registry отключён.
