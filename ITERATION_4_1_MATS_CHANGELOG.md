# Iteration 4.1 - распределение категорий по коврам

## Что исправлено

Ранее `assign_mats()` назначал ковёр каждому поединку циклически: 1, 2, 1, 2. Из-за этого матчи одной весовой категории могли проходить на разных коврах.

Теперь ковёр закрепляется за сущностью `Category`:

- одна возрастно-весовая категория всегда проводится на одном ковре;
- все `Match` этой категории наследуют `Category.mat_number`;
- возрастные группы сортируются от младших к старшим;
- при двух коврах младший возрастной блок получает ковёр 1, старший - ковёр 2;
- если возрастных групп больше, чем ковров, они распределяются непрерывными возрастными блоками, без дробления одной группы по разным коврам;
- `scheduled_order` считается отдельно внутри каждого ковра.

## Модель данных

Добавлено поле:

`Category.mat_number`

Миграция `0005_category_mat_number.py` назначает ковры уже существующим категориям и переносит это назначение в существующие поединки.

## Интерфейс

Номер ковра показывается:

- в таблице возрастно-весовых категорий;
- в шапке выбранной категории на экране сеток;
- в карточке каждого поединка.

## Демо-данные

В тестовых соревнованиях для сеток и итогового протокола теперь есть две возрастные группы:

- 2012-2013 - ковёр 1;
- 2010-2011 - ковёр 2.

Это позволяет сразу показать преподавателю, что весовая категория целиком остаётся на одном ковре.
