# Итерация 4 - данные спортсменов, категории и реалистичные тесты

## Реестр спортсменов

Добавлена модель `TeamMembership` и миграция `0004_teammembership.py`.

Теперь `Athlete` представляет одного человека независимо от количества соревнований. При импорте Word система:

1. определяет команду без создания дубля по регистру;
2. ищет спортсмена среди участников этой команды по ФИО и дате/году рождения;
3. если в команде совпадения нет, выполняет глобальный поиск существующего `Athlete`;
4. создаёт нового спортсмена только если однозначного совпадения нет;
5. создаёт или обновляет `TeamMembership`;
6. создаёт новое `Participation` только для конкретного соревнования.

При смене клуба старое участие остаётся связано с прежней командой, а в реестре новая связь становится текущей. Миграция автоматически заполняет memberships из уже существующих `Participation`.

## Весовые категории

Для демонстрационных соревнований теперь создаётся расширенный набор весов:

`32, 35, 38, 41, 44, 48, 52, 57, 62, 68, 75, 85, 92, 100, 110 кг`.

Это демонстрационный набор, а не зашитый норматив. В разделе категорий добавлена команда `Добавить набор весов`, которая создаёт категории сразу для выбранного диапазона годов рождения и пола. Отдельные категории по-прежнему можно добавлять и удалять вручную.

Обновлены `samples/application_template.docx` и `samples/application_example_filled.docx`.

## Тестовые результаты

`simulate_category()` больше не проставляет всем матчам 3:1, победу по баллам и красного победителя.

Демонстрационные результаты теперь детерминированно варьируются:

- победа красного или синего угла;
- по баллам;
- техническое превосходство;
- туше;
- неявка;
- медицинское снятие;
- дисквалификация;
- разные счета, согласованные со способом победы.

Для одного набора данных результаты повторяемы, поэтому демонстрация и тесты остаются стабильными.

## Интерфейс

Во всех исходниках пользовательские длинные тире заменены на обычный дефис. Из формы категорий убран длинный поясняющий блок.

## Тесты

Добавлены проверки:

- повторный импорт одного спортсмена той же команды не создаёт новый `Athlete`;
- при смене команды сохраняется один `Athlete`, но появляется новая связь `TeamMembership`;
- исторические `Participation` сохраняют команду конкретного соревнования;
- массовое создание набора весовых категорий не создаёт дубли;
- тестовая симуляция содержит победы обоих цветов, разные способы победы и разные счета.
