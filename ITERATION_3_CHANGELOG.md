# Итерация 3 - изменения

## Итоговый протокол

Добавлена модель `FinalProtocol` и миграция `0003_finalprotocol.py`.

Модуль формирует протокол только из данных текущего соревнования. Перед выпуском проверяется, что категории с допущенными спортсменами имеют сформированные и завершённые поединки, а итоговые места определены.

API:

- `GET /api/competitions/<id>/protocol/` - предпросмотр и готовность;
- `POST /api/competitions/<id>/protocol/` - окончательное формирование;
- `GET /api/competitions/<id>/protocol-download/` - DOCX.

Экспорт содержит сведения о соревновании, сводные показатели, медальный зачёт команд, призёров категорий, круговую классификацию и журнал завершённых поединков.

## Сетки

- круговая система разбита на раскрываемые круги;
- Nordic разбит на группы A/B, туры и финальный этап;
- прямое выбывание отображается древовидно с SVG-соединениями между матчами;
- квалификация и утешительные/бронзовые встречи отображаются отдельно;
- `Пережеребить` заменено на `Сформировать заново`.

## Интерфейс

- убраны длинные справочные тексты на рабочих экранах;
- выход очищает токены и выполняет полную загрузку `/login`;
- вкладка `06 Протокол` активна.

## Тесты

Добавлен `backend/competitions/tests/test_protocols.py`:

- блокировка протокола при незавершённых встречах;
- успешное формирование после завершения категории;
- проверка создания DOCX;
- проверка перехода соревнования в `finished`.

В этой среде выполнить Django-тесты не удалось, потому что нет сетевого доступа для установки Django из `requirements.txt`. Python-файлы прошли `compileall`, JavaScript из всех Vue SFC и `.js` прошёл `node --check`.
